# Meridian Roasters — Coffee Product Page

A static coffee product page built with plain HTML, CSS, and JavaScript. No build step required.

**Live page:** https://ahsansattar001.github.io/meridian-roasters-product-page/

## Structure

```
index.html            Page markup
assets/css/styles.css Styles
assets/js/icons.js    SVG icon sprite
assets/js/data.js     Product data and helpers
assets/js/cart.js     Cart drawer logic
assets/js/product.js  Gallery, options, reviews, related products
assets/images/        Product photos
```

## Run locally

Open `index.html` in a browser, or serve the folder:

```
npx serve .
```
